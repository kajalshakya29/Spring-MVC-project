## Employee Management System (Spring MVC + MySQL)  
📋 Overview

The Employee Management System is a web-based application developed using Spring MVC, JSP, and MySQL.
It allows administrators to manage employee records efficiently — including adding, updating, viewing, and deleting employee details through an intuitive web interface.

🚀 Features

Add new employees

Update employee details

Delete employee records

View a list of all employees

Database integration with MySQL

MVC architecture for clean separation of logic

Form validation and user-friendly interface

🏗️ Tech Stack

Backend: Java, Spring MVC
Frontend: JSP, HTML, CSS
Database: MySQL
Server: Apache Tomcat 9.0
Build Tool: Maven

🧠 Learning Objectives

Understanding MVC pattern in Spring

Working with DAO and Service layers

Integrating JSP views with controllers

Performing CRUD operations with MySQL
